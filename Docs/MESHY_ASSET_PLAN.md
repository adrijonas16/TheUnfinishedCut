# Plan de assets Meshy — vertical slice 0.1

## Política acordada

- Buscar y descargar modelos existentes antes de generar cualquier cosa.
- No iniciar generaciones ni gastar créditos sin avisar y recibir aprobación.
- Verificar licencia, formato y posibilidad de uso en videojuegos antes de incorporar un modelo.
- Preferir FBX o GLB, low-poly, texturas PBR y rig/animaciones cuando correspondan.

## Prioridad

No gastar créditos hasta que el blockout permita completar el ciclo:

1. Ivo activa la consola.
2. Nilo abre el conducto.
3. Ivo activa el proyector.
4. El mundo cambia.
5. Ambos alcanzan la salida.

**Descripción de búsqueda:**
